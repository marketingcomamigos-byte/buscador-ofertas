# OFERTAS+ V31

Atualização visual e mobile baseada na V30.

## Alterações
- Botões "Ofertas do Dia" e "Buscar Ofertas" reorganizados para celular, com largura confortável, espaçamento e área de toque maior.
- Barra de busca adaptada para telas pequenas.
- Cards de outras lojas com borda verde mais escura (#2f9e44).
- Carregamento da busca e das Ofertas do Dia com animação: ícone vivo + três pontos coloridos pulsando.
- Mantida a instalação PWA no celular.
- Mantida a regra de Ofertas do Dia e atualização de 3 horas da API.
- Estrutura entregue na raiz do ZIP para facilitar o envio ao repositório ligado ao Vercel.
