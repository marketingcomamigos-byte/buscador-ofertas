# OFERTAS+ Amazon V1.9

Instalação: chrome://extensions -> Modo do desenvolvedor -> Carregar sem compactação.

Fluxo: conectar uma vez no painel administrativo; abrir produto Amazon Brasil; clicar no botão oficial da Amazon "Copiar link de associado". A extensão captura o texto via bridge MAIN-world/clipboard e importa automaticamente.

Fallback: botão "Ler link copiado e importar" no popup.
