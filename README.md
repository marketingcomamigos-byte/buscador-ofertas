# OFERTAS+ V29 — logos das marcas + bordas por marketplace + instalação PWA

Base: V28.

Mudanças desta versão:
- Shopee usa o símbolo da marca em imagem otimizada no selo do anúncio.
- Mercado Livre usa o símbolo da marca em imagem otimizada no selo do anúncio.
- Anúncios Shopee recebem borda laranja da marca.
- Anúncios Mercado Livre recebem borda amarela da marca.
- Anúncios das demais lojas recebem borda verde-claro.
- Mantida a instalação do OFERTAS+ como PWA em dispositivos móveis, com convite automático e instruções específicas para iPhone.
- O botão de instalação aparece mais cedo no primeiro acesso móvel quando a instalação ainda não foi realizada.
- A regra de Ofertas do Dia e a atualização automática de 3 horas permanecem da versão anterior.
